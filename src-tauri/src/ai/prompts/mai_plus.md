### MAI PLUS SG2002 HOST RULES
Confirmed MAI/mAI/uAI/muAI Plus or SG2002 means MaixPy 4 Python, project_type=kidbright_uai_plus, main/main.py. Original muAI V831 is a different deferred target. Never replace Plus with an ESP32 profile or use ESP-IDF C/idf.py/esptool/CMake/C block conversion/compiler repair for a Plus program.
- Primary task references: kidbright_uai_plus_python.md and kidbright_uai_plus_test_contracts.md. Full historical training/connection notes are guides/mai_plus.md and kidbright_uai.md; do not load these for a simple drawing/button task. Known public APIs do not require private sharing.
- New programs: create_project_workspace with Plus project_type and a matching python_example or complete custom main_python. Do not edit an older classic project. Finish every requested behavior/file before Keep; a circle/display/calibration seed alone does not complete a different requested test.
- For MP-001..128 call uai_plus_test_reference first. TEMPLATE_CHECKED selects a complete local template; DRAFT_REFERENCE needs actual implementation/review; NEEDS_SETUP needs stated fixture/config/calibration; HOLD permits discovery/manual planning only until evidence resolves the blocker. Never claim all prompts generated/physically tested from API presence. Matching MP templates pass test_id; unmatched tests must supply the complete requested main_python. MP-022 needs a real counter, not the MP-021 seed; MP-128 analyzes supplied results.
- Example mapping: capabilities MP-001..005; touchscreen MP-015; adc_buttons MP-021. Read the appropriate API contract. Display uses image buffer -> draw -> show. Baseline imports from maix: display, image, camera, app, time; display.Display(), image.Image(width,height,image.Format.FMT_RGB888), draw_string/draw_circle, show; while not app.need_exit(). Retrieve complete matching samples instead of inventing variants.
- Touch: touchscreen.TouchScreen(), read() -> x/y/pressed, available(0), close(). Buttons: maix.adc.ADC(0,adc.RES_BIT_12), read(); calibrate released/S1/S2 distributions before thresholds. Do not borrow classic GPIO buttons, historical fixed thresholds or MicroPython machine/neopixel APIs.
- External I2C: verify actual controller/backend/pinmux/connector and reuse the existing bus. i2c.list_devices is discovery; scan is active probing. Do not guess bus 5/A28/A29, scan internal camera/IMU buses, insmod modules or edit boot scripts automatically. Generic bus APIs do not prove an external-device driver or voltage tolerance.
- UI Connect Plus / Run Python / Stop Python uses USB RNDIS WebSocket shell; execution is user initiated. Keep first, connect, then user Run Python. Separate desktop fixtures, source generation, upload, physical execution and boot installation. Do not re-image/provision a board to match a version screenshot. Current compatibility baseline MaixPy 4.12.5 / Runtime 1.24.0 permits compatible newer runtime APIs, not universal physical certification.
- Preserve selected model through short followups. Confirm model only when ambiguous; display/buttons/camera/shared USB identifiers do not distinguish original V831 and Plus. Training/model deployment uses the model-specific source contract; do not substitute legacy disk-image services or platforms.
