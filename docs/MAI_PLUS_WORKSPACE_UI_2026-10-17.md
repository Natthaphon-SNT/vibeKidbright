## ใช้งานส่วนใดได้แล้ว

- เลือกบทเรียน KidBright32, μAI หรือ μAI Plus โดยไม่เปลี่ยนบอร์ดเป้าหมายของโปรเจกต์ ESP-IDF ที่เปิดอยู่
- นำเข้าภาพ PNG/JPG/WebP หรือเสียง WAV/MP3/OGG/M4A จากเครื่อง ขนาดไม่เกิน 20 MB ต่อไฟล์ ดูตัวอย่าง เพิ่ม/เปลี่ยนชื่อกลุ่ม ย้ายตัวอย่าง และนำตัวอย่างออก
- แยกชุดข้อมูลของการจำแนกภาพ การตรวจจับวัตถุ และการจำแนกเสียง พร้อมแสดงจำนวนตัวอย่างจริงในแต่ละกลุ่ม
- สลับภาษาไทย/อังกฤษเฉพาะพื้นที่เรียนรู้ ใช้ธีมสว่าง/มืด และควบคุมแท็บด้วยคีย์บอร์ด
- ดูชนิดไฟล์โมเดลที่สัมพันธ์กับบทเรียนที่เลือก ดู/คัดลอกตัวอย่างโค้ดเปิดกล้อง และเปิด Vibe Coder เพื่อคุยต่อ โดยยังไม่ส่งข้อความให้อัตโนมัติ
- เปิดคู่มือเตรียมบอร์ดในหน้าต่างภายในแอปทันทีจากทั้งปุ่มด้านบนและด้านข้าง อ่านออฟไลน์ได้ แยกขั้นตอน KidBright32 / μAI / μAI Plus และภาษาไทย/อังกฤษ พร้อมการแก้ปัญหาเบื้องต้น ปิดด้วยปุ่ม, Esc หรือคลิกนอกหน้าต่างได้ โดยข้อมูลบทเรียนยังอยู่

ข้อมูลฝึกหัดอยู่ในหน่วยความจำของหน้านี้ กลับไปเขียนโค้ดแล้วกลับมายังอยู่ แต่ปิดหรือโหลดแอปใหม่จะหาย ยังไม่มีการบันทึกชุดข้อมูลลงโปรเจกต์ ปุ่ม Build และทางลัด Build/Save ขณะอยู่ในพื้นที่เรียนรู้ไม่ส่งคำสั่ง build หรือเขียนโปรเจกต์ที่เปิดค้างไว้

## ส่วนที่ยังรอพัฒนา

กล้อง/ไมโครโฟนจากบอร์ด การฝึกและแปลงโมเดล การส่งโปรแกรมไป μAI/Plus และเครื่องมือวาดกรอบวัตถุยังไม่เปิดใช้งาน ปุ่มที่เกี่ยวข้องถูกปิดและระบุสถานะชัดเจน หน้านี้ยังไม่สร้างโปรเจกต์ Python หรือเพิ่ม active board profile ของ μAI/Plus ภาพบอร์ดเป็นภาพประกอบ ไม่ใช่ผังขาสัญญาณ

งานเชื่อมต่อจริงให้ดำเนินต่อจาก [แผนรวมบอร์ด](VIBEKIDBRIGHT_UNIFIED_BOARD_ARCHITECTURE_2026-10-17.md) และ [ผลตรวจซอร์สต้นฉบับ](KIDBRIGHT_MAI_GITHUB_RESEARCH_2026-10-17.md) ตามลำดับความสำคัญเดิมที่ทำ KidBright32 ให้สมบูรณ์ก่อน

## การตรวจสอบ

ชุดทดสอบ frontend ผ่าน 145 tests ใน 12 files รวมการนำเข้า/จัดกลุ่ม/ล้าง URL การเปลี่ยนภาษา การใช้คีย์บอร์ด และการกลับไปมาโดยโค้ดที่ยังไม่บันทึกคงอยู่ ตรวจหน้าแอปใน Chrome ที่ความกว้าง 1536, 1280, 1024 และ 800 px ไม่พบการล้นแนวนอนหรือ JavaScript page errors รายละเอียดและ hash ของไฟล์อยู่ใน [หลักฐานตรวจ UI](research/mai-plus-ui-2026-10-17-validation.json)

การแก้ไขนี้เป็นซอร์สแอปและ frontend build ยังไม่ได้สร้าง installer หรือติดตั้งทับแอปบน desktop และยังไม่มีผลทดสอบฮาร์ดแวร์ μAI/Plus

ผลแก้ปุ่มคู่มือวันที่ 18 ตุลาคม 2026 และขอบเขตการทดสอบอยู่ใน [รายงานคู่มือภายในแอป](ai-engineering/15-board-guide-ui.md) ตัวเลขการตรวจสอบด้านบนเป็นผลรอบเดิม
