# vibeKidbright 3.7.4

วันที่ 21 ตุลาคม 2026

แก้การติดตั้ง ESP-IDF toolchain บน Windows ที่ล้มเหลวด้วยข้อความ
`failed to persist temporary file: The system cannot find the path specified. (os error 3)`
เมื่อ path ของไฟล์ที่แตกจาก ZIP ยาวเกิน 260 ตัวอักษร

- รองรับ path ยาวทั้งไฟล์ชั่วคราวและปลายทาง รวมโฟลเดอร์ซ้อนลึกและการแทนที่ไฟล์เดิม
- แก้การตรวจขอบเขตโฟลเดอร์ที่เคยปฏิเสธ path ยาวบน Windows โดยยังตรวจ traversal, links และ reparse points
- ตั้งค่า Python venv หลังย้าย toolchain ไปยังโฟลเดอร์ปลายทาง เพื่อไม่ให้อ้างถึง `.installing` ที่ถูกย้ายแล้ว
- แจ้งพร้อมใช้งานหลังเปิดใช้งาน toolchain สำเร็จ
- แสดงข้อความผิดพลาดเต็มที่เลือกคัดลอกได้ในหน้าติดตั้งแบบย่อ พร้อมเพิ่ม error ลง log
- อัปเดตเวอร์ชัน npm, Cargo, Tauri และ lockfile เป็น 3.7.4

## การตรวจสอบ

มี regression tests สำหรับ path ยาวบน Windows การเขียนทับไฟล์เดิม
การตั้งค่า Python ไปยังโฟลเดอร์ปลายทาง และการแสดง error/ลองติดตั้งใหม่
ผลตรวจและ SHA256 ของตัวติดตั้งที่สร้างในเครื่องบันทึกใน [3.7.4-validation.json](3.7.4-validation.json)

ตัวติดตั้ง Windows x64: `VibeKidbright IDE_3.7.4_x64-setup.exe`

ยังไม่ได้ทดสอบดาวน์โหลดและติดตั้ง toolchain ทั้งชุดจากเครือข่ายจริง หรือทดสอบวงจร
ติดตั้ง/อัปเกรด/ถอนการติดตั้งบน clean VM รุ่นนี้ยังไม่ได้เผยแพร่บน GitHub Releases
