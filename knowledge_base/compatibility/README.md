# Reference C sources in the 3.7.1 knowledge base

The C files here come from the current classic KidBright reference collection. They are source data for drafting, not native recipes registered in this maintenance release. Historical software builds of the reference collection are not new hardware or firmware tests of 3.7.1. Read ../support_scope.md and the matching versioned board document.
